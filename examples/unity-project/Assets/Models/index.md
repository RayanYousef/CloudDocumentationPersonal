# Models

FBX meshes stored via Git LFS. Pivot at floor contact, +Z forward, unit scale; collision meshes are named `<Name>_Col` inside the same file.

## Files

* [Airship.fbx](Airship.fbx) - player airship with LOD group and the Socket_* transforms gameplay code binds to.
* [Chest.fbx](Chest.fbx) - 24-slot storage container prop with separate animated lid mesh.
